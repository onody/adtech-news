## 1. OpenAI、ChatGPT広告のセルフサーブ管理画面を一般開放

**ASIS**: 2026/02から ChatGPT の Free / Go ティア（米国・ログイン済み成人）で広告パイロット。出稿は直販・限定枠のみで、事実上エンプラ営業経由。

**TOBE**: 7/22 に「Advertise in ChatGPT」を公開。キャンペーン作成・予算設定・ターゲティングをセルフサーブで完結でき、CPC入札と計測ツールが追加された。ターゲティングの主キーは検索キーワードではなく**会話コンテキスト**。事例として Best Buy / Lowe's / VistaPrint。

**何が新しいか**: 「実験」から「買える在庫」への転換点。キーワード→会話コンテキストという単位変更は、既存の検索広告の入札・計測モデルがそのまま移植できないことを意味する。有料プラン（Plus/Team/Enterprise）は引き続き広告なしで、リーチ上限はフリーユーザー側に固定される。

https://openai.com/index/new-ways-to-buy-chatgpt-ads/

## 2. Google、Performance Max に在庫除外コントロールを開放（パイロット）

**ASIS**: PMax はチャネル配分がブラックボックス。2025年以降にチャネル別レポート、キャンペーン単位の除外キーワード、1stパーティ audience 除外が段階的に追加されたが、配信先そのものは切れなかった。

**TOBE**: 6月下旬から限定パイロットで、**サードパーティ検索パートナー**と**Google Display Network** をチェックボックスで除外可能に。デフォルトはON（＝配信される）で、任意にOFFにできる。

**何が新しいか**: 「配信先を切る」権限をGoogleが初めて手放した。PMG は制御が入ったことで PMax 投下額が平均10%増えたと報告しており、透明性の欠如が予算のボトルネックだった構図がはっきりした。ただし多くの代理店がまだ機能に触れられておらず、ロールアウトは相当絞られている。

https://digiday.com/media-buying/google-quietly-gives-ground-on-pmax-controls/

## 3. Google Ads、規約改定と AI Max 本格移行のロードマップが確定

**ASIS**: AI Max は検索キャンペーン向けのベータ。DSA（動的検索広告）と併存。アトリビューションは first click / linear / time decay / position-based が選択可能。

**TOBE**:
- 7/1 に改定規約が全アカウントへ自動適用。Google の自動化システムが広告主に代わって「ターゲット・広告・遷移先を生成／選択／整形する」ことを明文で認可。
- AI Max がベータを卒業。**9月から DSA が AI Max へ自動アップグレード開始、2027/02 に DSA 完全廃止**。
- 7月中旬より、ラストクリック／データドリブン以外のアトリビューションモデルが選択不可に。
- PMax に自動生成画像と動画生成が追加。

**何が新しいか**: 廃止日が入ったこと。DSAのフィード運用やアトリビューション設定に依存した実装は 2027/02 が期限になる。規約改定は「勝手に生成された広告文の責任範囲」を実務上どう握るかという新しい論点を生む。

https://ppcnewsfeed.com/google-ads-updates/2026-07/

## 4. IAB、ストリーミング在庫の品質分類標準「RMTS」ドラフト公開

**ASIS**: CTV/デジタル動画の在庫は「CTV」という粗い括りで売買され、大画面を買ったつもりがモバイルや公共ディスプレイに混ざる。価格が実際の経済価値に対応していない。

**TOBE**: **Redefining Media Types Standard (RMTS)** が2軸で在庫を分類する。
- 視聴環境: large screen（家庭のTV） / personal screen（モバイル） / public ambient display（空港サイネージ等）
- 運用属性: 音声の有無、スキップ可否、ターゲティングシグナル、ジャンル、ライブか再放送か

これをキャンペーン設定でプログラマティックに指定できるようにする。

**何が新しいか**: 品質が「文章での約束」から「機械可読なタクソノミー」になる。IAB自身が、エージェンティックな自動買付でAIに品質閾値を教えるためのガードレールとして位置づけている点が重要。RMTS が入ると入札ロジック側に新しい次元が増える。

https://digiday.com/future-of-tv/future-of-tv-briefing-the-streaming-ad-industry-finally-has-levers-to-pull-on-quality/

## 5. W3C Attribution API に「大手プラットフォーム有利」の批判

**ASIS**: ポストCookieのアトリビューション標準として W3C で策定中。マルチパーティ計算＋差分プライバシーで、個人単位ではなく集計統計としてコンバージョンを返す。ブラウザ承認済みの aggregation service をサイト側が選択する構成。

**TOBE**: wide review 段階に入り、学識者・CDT・IAB Tech Lab・NAI が意見提出。**2026年末に W3C 勧告化見込み**。反対意見の中身は以下。
- Don Marti (Aloodo): 検索・ソーシャル・アプリストア広告に**恒常的な統計バイアス**がかかり、Apple / Google / Meta が有利、ニュースパブリッシャーが不利になる。さらにアトリビューション不正を隠蔽・報酬化し、より広範なデータ収集を誘発する。
- Angelina Eng (元IAB US): マーケター側は独自モデルを組めるイベントレベルの生データを望んでおり、ブラウザ側の制約が乗った集計済み出力では要件を満たさない。
- W3C のWG構造そのものが、参加リソースを持つ大組織に有利。

**何が新しいか**: 技術仕様の議論から、**バイアスが誰の利益に効くかという配分の議論**に完全に移った。年末勧告が既定路線なので、計測基盤の再設計を待つ側にとってはここが最後の設計変更のチャンス。

https://digiday.com/marketing/fears-of-big-tech-bias-underpin-debates-around-w3cs-attribution-api/

## 6. Amazon DSP、オフラインCVを「どの小売店で売れたか」まで分解

**ASIS**: Omnichannel Metrics は Amazon DSP 配信が Amazon 外の売上にどう効いたかを計測。ただしオフライン購入は単一の「offline」という塊で返っていた。

**TOBE**: 7/7 より、オフライン購入を**発生した小売店単位**で分解し、店舗別のユニット数・売上を返す。

**何が新しいか**: 「Amazon外でも効いてます」という定性主張が、リテーラー名の入った定量データになった。ブランド側は小売別のリテールメディア予算配分に直接使える。Amazonが競合小売の売上データを握って可視化しているという構図でもある。

https://ppc.land/amazon-dsp-now-names-the-specific-retailers-its-ads-drive-sales-to/

## 7. The Trade Desk、Publicis離反とSSPリセラー分類で四面楚歌

**ASIS**: 独立系DSPの筆頭。オープンウェブの中立的な買い手というポジション。

**TOBE**:
- 株価が年初来**-76%**、EV 7.36B ドル（調整後EBITDA の約6倍）まで下落。
- Publicis が「fees の積み上げ」と無承認課金を理由に、**全クライアントに TTD 利用停止を助言**。
- CFO が2ヶ月で2人退任。
- TTD が SSP を「リセラー」に分類する方針に対し、SSP各社が反発。
- 一方で PubMatic とは、パブリッシャー／広告主間で deal メタデータをリアルタイム共有する API で協業。
- 背景に Amazon DSP の攻勢。

**何が新しいか**: 単発の悪材料ではなく、**買い手（代理店）・売り手（SSP）・競合の三方向から同時に押されている**こと。オープンウェブのプログラマティックにおける中立的ハブという前提そのものが揺れている。

https://www.adexchanger.com/programmatic/wall-street-wants-to-know-what-the-programmatic-drama-is-about/

## 8. Netflix 広告プラン、月間アクティブ2.5億に到達

**ASIS**: 2025/11 時点で月間アクティブ視聴者1.9億。提供12ヶ国。広告主4,000社超（前年比+70%）。

**TOBE**: **2.5億MAU**に到達し、広告プラン会員の80%超が毎週視聴。オーストリア、ベルギー、デンマーク、オランダ、ポーランド、スウェーデン、スイス、インドネシア、フィリピン、タイなど**15ヶ国を追加**。2026年の広告売上は倍増の30億ドル、2030年に90億ドル目標。Sony Pictures との契約で広告プランの視聴不可タイトルも大幅減。

**何が新しいか**: リーチの絶対量がCTV在庫の価格交渉力に転換する段階に入った。提供12ヶ国では新規登録の60%超が広告プランで、「安いから広告版」がデフォルト行動になっている。

https://variety.com/2026/tv/news/netflix-claims-ad-tier-reaches-250-million-viewers-1236746219/
